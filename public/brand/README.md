# Local brand assets

These files are downloaded originals, stored locally so the app needs no runtime image service. Logo and cups imagery match the visual references supplied by the user. Brand artwork and photographs retain their original ownership; this prototype does not claim authorship or endorsement.

- `love-creamery-logo.jpg`: winged ice cream logo, from https://www.lovecreamery.com/wp-content/uploads/2022/04/love-creamery-logo.jpg
- `love-creamery-cups.jpg`: two cups on a blue background, from https://images.squarespace-cdn.com/content/v1/502f1b77e4b0adcdbccc3b8c/1689876622022-Y8UILTJFEO4VX30GJ3O6/LoveCreamery-Cups+copy.jpg?format=1500w . Source portfolio: https://www.matthewolin.com/love-creamery/ . Packaging project credits Matthew G. Olin and Jacey Kufahl, 2020–2022; the portfolio does not name a separate photographer.
- `love-creamery-lincoln-park.jpg`: Lincoln Park storefront, from https://www.lovecreamery.com/wp-content/uploads/2021/06/love-creamery-Lincoln-Park-shop.jpg . This supporting image comes from the official site and is not the low-resolution photo embedded in the chat.

Retrieved October 19, 2026. Photography is displayed independently of fictional flavor cards and does not confirm ingredients, allergens, shop conditions today, or current availability.

Configure image paths, alt text, and credits in `src/brand.json`. Paths must be relative, without a leading slash, for GitHub Pages project URLs. No image API, image-generation service, or remote runtime dependency is used.
