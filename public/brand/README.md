# Brand assets

Put approved logo artwork and real photography here, then set `logoImage` and `heroImage` in `src/brand.json` to paths such as `brand/love-creamery-logo.svg` and `brand/ice-cream.jpg`. Paths must be relative (no leading slash) so GitHub Pages project URLs work. Add accurate `heroAlt` and `heroCredit`. Assets are served locally, without external runtime requests.

No official logo or photography is currently bundled: the official site, portfolio, and photo source were blocked during this update. The fallback winged scoop is an original illustration, not the official Love Creamery logo. Do not label synthetic imagery as photography or associate generic photos with a real flavor or dietary status.
